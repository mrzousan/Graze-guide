# Graze Guide

Can my tortoise eat it? A pocket guide to which California plants and foods are safe for Hermann's and other Mediterranean tortoises.

This is a test version. Ratings are drafts still being checked against sources and have not been reviewed by a reptile vet. Don't use it to decide what to feed.

## Install on your phone

Open the site in Safari (iPhone) or Chrome (Android), then:

- **iPhone:** Share → Add to Home Screen
- **Android:** ⋮ menu → Add to Home screen (or Install app)

After the first visit it works offline.

## What's inside

- `index.html` — the app, including the plant data and sources
- `manifest.webmanifest` — name and icons for installing
- `sw.js` — offline support
- `icons/` — app icons
